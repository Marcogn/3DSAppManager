# v2.4.1 - Polish and Fixes

**Data:** 2026-02-04

## Modifiche Implementate

### 1. ✅ Selezioni Preservate Durante Sort
**Problema:** Sorting resettava tutte le selezioni.

**Soluzione:**
- Rimossa logica di reset delle selezioni in `sortTitles()`
- Le checkbox rimangono selezionate anche dopo cambio sort
- Solo cursor e scrollOffset vengono resettati

**Beneficio:** Puoi selezionare i titoli, poi cambiare sort per vedere l'ordine, e le selezioni rimangono.

### 2. ✅ Info Bar Riorganizzata
**Problema:** Quando si filtrava (Y), "[Updates]" o "[DLC]" appariva sotto "Selected", sovrapponendosi.

**Soluzione:**
- Filtro spostato accanto al contatore totale: `T:450 [Upd]` o `T:450 [DLC]`
- Label abbreviate per risparmiare spazio:
  - "Titles:" → "T:"
  - "Selected:" → "Sel:"
  - "Sort:" → "Sort:"
- Posizioni X aggiustate: 5px, 95px, 170px

**Layout finale:**
```
T:450 [Upd]  Sel:3  Sort:Size
```

### 3. ✅ Sort by Size in Ordine Decrescente
**Problema:** Sort by size mostrava i titoli piccoli prima, richiedendo scroll per trovare i grandi.

**Soluzione:**
- Invertito `compareTitlesBySize()`:
  - Prima: `ta->size < tb->size` (crescente)
  - Ora: `ta->size > tb->size` (decrescente)

**Risultato:** I titoli più grandi appaiono in cima alla lista.

### 4. ✅ Overlay Controlli Migliorato
**Problema:** "Press any button to close" tagliato a metà dalla riga azzurra del bordo.

**Soluzione:**
- Box ingrandito: da 360x200 a 370x210
- "Press any button" posizionato dentro il box (y = boxY + boxH - 20)
- Layout tabellare con 2 colonne:
  - Colonna 1 (x=15): Nome tasto (giallo/arancione)
  - Colonna 2 (x=140): Descrizione (bianco)
- Righe indentate per continuazioni (es. "(Name/Size/TID)")

**Layout:**
```
CONTROLS

A                Select/Deselect
X                Uninstall selected

D-Pad Up/Down    Navigate list
D-Pad Left/Right Page jump

L                Sort backward
R                Sort forward
                 (Name/Size/TID)

Y                Filter mode
                 (All/Updates/DLC)

SELECT           Show this help
START            Exit app

     Press any button to close
```

### 5. ✅ Punto Interrogativo Centrato
**Problema:** Il "?" nel placeholder dell'icona era sempre scentrato.

**Soluzione:**
- Coordinate aggiustate: X=24.0f, Y=y+8
- Scala aumentata: 2.0f (più grande e visibile)
- Calcolo preciso per centratura nel quadrato 48x48px
