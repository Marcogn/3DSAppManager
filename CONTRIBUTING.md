# Contributing to 3DS Fast Uninstall

Thank you for your interest in contributing!

## Development Setup

1. Install [devkitARM](https://devkitpro.org/wiki/Getting_Started)
2. Clone the repository
3. Run `make` to build

## Code Style

- Use clear, descriptive variable names
- Add comments for complex logic
- Follow the existing code structure
- Test thoroughly before submitting

## Submitting Changes

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Test your changes
5. Submit a pull request with a clear description

## Areas for Improvement

- Better error messages and detailed error handling
- Support for additional archive types
- Progress bars during backup/deletion
- Icon customization
- Multiple language support
- Restore functionality from backups

## Testing

Since this requires a Nintendo 3DS console, please test thoroughly on actual hardware before submitting PRs.
