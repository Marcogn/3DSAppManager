# Release v1.0.1 - UI Improvements

## Changes

- **Clear bottom screen during title loading**: The bottom screen now displays a clean blue background while loading titles, instead of showing the previously selected titles list
- **Improved clarity**: Changed "SELECTED TITLES" to "TITLES TO BE REMOVED" for better user understanding of what will happen
- **Better user experience**: When reloading titles after uninstalling, the bottom screen is properly cleared

## Files to include in the release

- `3ds-fast-uninstall.3dsx` (main executable)
- `3ds-fast-uninstall.smdh` (icon metadata)

## Installation

1. Copy `3ds-fast-uninstall.3dsx` to `/3ds/` folder on your SD card
2. Launch from Homebrew Launcher

## Notes

This is a minor UI improvement release to make the application more user-friendly.
